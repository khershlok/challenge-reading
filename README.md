# Challenge Reading

Weekly reading for the General paper of The Challenge at Westminster School (first examination 2027).

- **Lessons:** written each Sunday from that week's news (content/weeks/), unlocking on Monday.
- **In the news:** real articles from BBC News, The New York Times, The Economist, The Guardian, The Conversation, Aeon and Psyche (content/news.js).
- **Roque (AI tutor):** a Gemini chat that opens from the header on every page. Each visitor pastes their own Gemini API key, kept in their browser.
- **News log:** research/news-log.md, filled in by a news-reading loop several times a day.

Live site: https://khershlok.github.io/challenge-reading/
